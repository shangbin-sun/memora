# 图谱抽取：中文具体关系与家庭上下文推理

## 抽取约定

图谱仍由 LLM 一次理解当前 `source_text`，不增加关键词黑名单、不在程序中拼接亲属关系，也不新增逐实体二次 LLM 调用。沿用现有分块、请求预算和 600 秒总截止。

- `relation` 使用简短、具体的中文谓词，开放词汇，不以“属性／有属性／关系／关联”兜底。例如 `林子航 → 小名 → 航航`、`林志远 → 工作单位 → 某公司`。
- 既有英文受控词汇继续兼容规范化，展示层不再把已经中文化的关系转回英文。未知历史开放谓词不会靠字典猜译或强行改义。
- 小名、别名、称呼、姓名作为主体的带来源文本属性保留，不把昵称值建为另一个人物。已有 `有属性 + attrs.alias_kind` 输入可以按已声明的 subtype 具体化；没有 subtype 的旧泛关系无法仅凭程序确定其含义。

## 家庭关系方向与推理

方向统一为：**宾语是主语的什么人**。

```text
林子航 → 爸爸 → 林志远
林志远 → 儿子 → 林子航
林子航 → 妈妈 → 宋娜娜
宋娜娜 → 儿子 → 林子航
林志远 → 老婆 → 宋娜娜
宋娜娜 → 老公 → 林志远
```

以上不是按名字预设的数据。只有当前原文支持相应关系时，LLM 才输出这些边；允许结合跨句、表格行列及已消歧的上下文判断，不要求每条反向关系都被逐字说出。家庭边使用 `domains:["household"]`。

推理边在 `attrs` 中保存：

```json
{
  "assertion_basis": "context_inference",
  "inference_note": "简短、可核验的依据摘要",
  "evidence_spans": ["当前原文中的前提一", "当前原文中的前提二"]
}
```

`evidence_spans` 必须非空，各段必须连续出现在当前 `source_text`；`evidence_text` 取其中一段，不拼接伪引文。程序验证证据格式和出处，**不冒充能证明推理正确**。直接断言不必携带这些新增字段。

边界：不凭姓名猜性别；不把共同有孩子等同夫妻；不把父亲配偶自动等同生母；性别不清楚可用“子女”；歧义进 `pending`。否定、前任、暂停、条件及来源隐私必须保留。

本轮仅支持**当前来源内**的上下文推理，不检索其他记忆作为额外前提。现有图谱多来源表示独立支持，不是逻辑 AND 前提链，不能把跨来源推理接上去而绕过撤回或权限检查。私密来源仍限制授权主体，不为反向边扩大任何成员权限。

## 实体及引用安全

- 新 LLM `triples` 的两端只能引用本批 `entities` 已声明且通过验证的 `temp_id`。未定义的 `e2` 进入待确认，不按字符串创建同名节点。
- 若模型把自身临时 ID 复制为名称且原文不支持，拒绝该实体；原文明指的 E2 设备、公共交通等正常保留，不按词面屏蔽。
- `公共` 等保留成员 ID 是文字记忆的归属范围，不是人物。图谱名册锚点、解析、查询排除这类 scope 人物；需要表达共同家庭事实时使用真正的 family 类型节点。文字记忆的公共归属不变。
- 旧入库接口仍兼容已有名称输入，但声明了实体的批次不会对未解析临时引用兜底创建新节点。

## 查询与展示

具体谓词保持方向，不压回“亲属”或“属性”。已知中英文关系授权按同一规范化形式比较；不扩大到全部属性/全部亲属。别名查询、展示仍经过来源、隐私、状态和授权检查。

Web 图谱使用方向箭头，将反向关系及同一对成员间的多条关系分离为曲线和独立标签；昵称文本属性仍可显示为关系终点，不另造持久人物。显示推理标记只说明来源类型，不代表推理已人工确认。

## 历史数据与验证范围

不执行历史数据库删除、全局关系替换或自动重建。公共 scope 人物不再作为有效人物展示，但数据库原记录未删除；历史 `e2` 或含义不明的泛“属性”仍需要在确认重建范围后根据原证据重新抽取。

回归包括：中文具体属性与家庭方向、LLM 推理证据契约、未定义引用、不按词面误删合法短名称、公共 scope、别名隐私及撤回、关系授权兼容、SVG 双向箭头及标签分离。模拟输出/纯模块测试验证协议和实现，不代表真实模型抽取准确率；应另用家庭真实样本评估误报、漏报和推理正确率。

本机离线验证结果：

- 隔离 manifest 直接编译生产解析器、本体、类型和提示模块，旧协议转换使用实际函数：33/33 通过（包含重复临时 ID 的同身份去重、冲突身份拒绝）；实际别名引用 helper 配合生产类型再测 3/3，共 36/36。不覆盖 SQLite、事务和引擎。
- 实际 app.js 的 VM/最小 DOM 图谱方向回归 5/5，通过既有召回 2/2、reconcile 6/6，共 13/13；不是完整浏览器视觉验收。
